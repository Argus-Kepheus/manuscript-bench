# Per-Model Error Breakdown & Comparative Ranking

Generated by auditing all 12 `LLMs/*/corrected-text.md` and `LLMs/*/LaTeX-output/main.tex`
files against the source text (`LLMs/Prompt-input.md`) and `Prompt.md`'s own rules. Full
detail on every data alteration is in [`HALLUCINATIONS.md`](HALLUCINATIONS.md); this document
scores and ranks the 12 models from that same evidence.

**Context.** The outputs being compared were generated and committed to this repository on
**2025-10-31**, so this ranking reflects each model's behavior on that date, on this one
task — a single retrospective medical case-report revision. The listed model identifiers
come from each paper's own author block, where given: ChatGPT → *GPT-5*, Claude → *Claude
Sonnet 4.5*, Maritaca → *Sabiá-3.1*, Meta → *LLaMA 3.3*, Perplexity → *Sonar* (Perplexity's
underlying answer-engine model); Copilot, DeepSeek, Gemini, Grok, Le Chat, Qwen, and You
did not record a specific model version in their output, only the company name. **This is a
sample size of one document per model** — a single trial, not a statistically robust
benchmark. Treat the ranking as a structured read of this one comparison, not a general
claim about model quality.

## Scoring criteria

Each model is scored across four axes, weighted in this order (most to least important,
matching Prompt.md's own stated priorities):

1. **Data fidelity** — did it preserve the source's case-specific facts (temperature, in
   particular) without silent alteration?
2. **Fabrication** — did it invent content not present in the source (subtitles, DOIs,
   merged citations, terminology swaps) without flagging it?
3. **Completeness** — how much of the source's clinical detail and required structure
   (Methods, citations converted, bibliography populated) survived into the output?
4. **Citation/reference integrity** — how well did it handle the source's already-garbled
   Azzopardi citation and other reference-list defects?

## Reading the ranking

- **Ranks 1–5** (Copilot, ChatGPT, You, Qwen, Perplexity) never altered a source fact and
  never fabricated content. They're separated only by completeness and file/citation hygiene
  — Qwen's file-corruption bug and Perplexity's author-list truncation are real defects, but
  neither touches the substance of the clinical text.
- **Ranks 6–9** (Claude, DeepSeek, Grok, Le-Chat) all made the same unflagged move: silently
  conforming the patient-specific 32–35°C figure to the 33–34°C literature average from the
  Introduction. This is the single most common data-fidelity violation in the set — 4 of 12
  models made it independently. Grok and Le-Chat compound it with invented title content;
  Grok partially offsets this with the best citation handling of any model in the repository.
- **Ranks 10–12** (Gemini, Maritaca, Meta) each have a distinct, more structural problem:
  Gemini's is diligence (didn't clean up anything inherited from the source), Maritaca's is
  citation/document integrity (a fabricated merged citation and a duplicated Methods
  section), and Meta's is completion (didn't do most of the task).

## What this does *not* show

- This is one document, one domain (a short medical case report), one point in time, and one
  interface per model (web chat, per `README.md`'s workflow) — not an API benchmark, not a
  reasoning-effort-controlled comparison, and not representative of these models' general
  citation or medical-writing ability.
- "Preserved data fidelity" and "best" are not synonyms for "most capable" — a model that
  produces less content, or truncates more conservatively, can score well here for reasons
  unrelated to overall quality (e.g., Copilot and You's outputs are also comparatively shorter
  and less stylistically ambitious than, say, Le-Chat's or Maritaca's).
- None of the 12 outputs include the mandated Processing Report section (see
  `HALLUCINATIONS.md` §3), so this ranking relies entirely on our own diff against the source
  rather than each model's self-reported changes and flags — which is exactly the audit
  Prompt.md intended each model to produce for itself.
